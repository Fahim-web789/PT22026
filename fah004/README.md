# LoRA-Adapted Visual Question Answering for Chinese Cultural Heritage Based on ChinaHeritaQA
Professional Training Course Project

## Project Description
This is a bilingual (Chinese / English) VQA system for cultural heritage relics.
We use Qwen-VL-Chat as the base multimodal model and use LoRA lightweight fine-tuning on ChinaHeritaQA dataset.
The user can upload heritage images and ask questions in Chinese or English. A Gradio web UI is provided for interaction.
